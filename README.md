## Featured Projects

### [Procedural 2D Map Generation Analysis](https://github.com/Lelikoth/pcg-test-enviro)

**Godot 4 · GDScript · Procedural Generation · Algorithms**

A modular environment for implementing, testing, and comparing procedural 2D map generation algorithms under consistent experimental conditions.

The project includes five generation approaches:

- Random Walk
- Perlin Noise
- Cellular Automata
- hybrid BSP + Cellular Automata
- custom module-based Wave Function Collapse

It also provides:

- deterministic seed-based generation
- automated batch testing
- map validation
- pathfinding and connectivity analysis
- structural and entropy metrics
- performance measurements
- CSV and PNG export

---

### [ECG TimeGAN](https://github.com/Lelikoth/ECG-Timegan)

**Python · PyTorch · Machine Learning · Time-Series Data**

A machine learning project focused on ECG classification and synthetic data augmentation using **TimeGAN**.

The project covers:

- ECG data preprocessing
- synthetic time-series generation
- baseline and augmented classification experiments
- synthetic data quality evaluation
- model analysis
